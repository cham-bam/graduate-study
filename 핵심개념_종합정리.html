질문정확한 위치/답
State가 사전학습 내용인가?아님. State는 prompt, conversation history, 지금까지 생성한 토큰. 사전학습 지식은 policy model의 파라미터 안에 있음.
Post-training은 추론인가?학습 단계. 답변 생성은 inference처럼 보이지만 reward 후 파라미터 업데이트가 있으므로 training.
RL은 top-p 후보 토큰 보상 조절인가?아님. Sampling으로 실제 생성한 응답/토큰 경로에 reward를 주고 그 log probability를 업데이트.
RLHF의 pairwise란?두 응답 중 더 좋은 것을 고르는 인간 선호 데이터. Bradley-Terry가 P(y_w>y_l)=σ(r_w-r_l)로 모델링.
RLVR verifier는 대형 모델인가?꼭 아님. 정답 비교기, unit test, 규칙 checker가 될 수 있고, 경우에 따라 LLM judge도 가능.
RAG-Token이 CoT를 시작시키나?아님. RAG-Token은 문서 조건화 방식, CoT는 reasoning prompting. 둘은 독립이지만 결합 가능.
Emergent ability와 Aha moment는 같은가?다름. Emergent는 규모 증가에 따른 능력 출현, Aha moment는 RL 중 자기검토 전략이 나타나는 학습 과정 현상.
LoRA와 LLaVA는 같은 low-rank인가?LoRA는 low-rank update가 핵심. LLaVA는 CLIP feature를 LLM embedding 공간으로 projection하는 멀티모달 구조.
Sigmoid와 Softmax 차이?Sigmoid는 reward 차이 같은 단일 점수를 0~1로, Softmax는 여러 후보 logits를 합 1의 확률분포로 변환.
답안 작성 순서: 학습 시점/추론 시점 → 파라미터 업데이트 여부 → reward 또는 context의 출처를 먼저 쓰면 대부분의 혼동을 피할 수 있다.

③ PEFT — 효율적 Fine-tuning▼
★★★반드시 출제 LoRA
ΔW = B · A
B ∈ R^(d × r), A ∈ R^(r × d), r ≪ d
원본 파라미터: d² → LoRA: 2dr → 절감: d/(2r)
// 비정사각형: r(d_in + d_out)
  • ΔW = BA (등호, ≈ 아님)
  • 추론 시 B·A 를 W에 병합 → 추가 지연 없음
  • 계산 예: W∈R^(768×768), r=8 → 원본 589,824 vs LoRA 12,288 → 48배 절감

① Scaling Laws▼
★★유력 Power-law 관계
L(N) ∝ N^(-α) // 모델 크기와 loss
L(D) ∝ D^(-β) // 데이터 크기와 loss
L(C) ∝ C^(-γ) // 컴퓨팅과 loss
  • 세 요소(N, D, C) 모두 늘리면 loss가 예측 가능하게 감소
  • Chinchilla law: 고정 compute에서 N과 D를 균형 있게 → compute-optimal
  • GPT-3는 Chinchilla 기준 모델 과대 / 데이터 과소
기호뜻해석 포인트
N모델 파라미터 수모델 용량. 클수록 표현력은 커지지만 학습 데이터가 부족하면 undertrained가 됨
D학습 데이터 토큰 수모델이 실제로 본 텍스트 양. 큰 모델일수록 충분한 D가 필요
C학습 compute대략 C ≈ 6ND. 고정된 C 안에서 N과 D를 어떻게 나눌지가 핵심
Power-law: N, D, C를 키우면 loss가 급격히 한 번에 떨어지는 것이 아니라, 로그-로그 그래프에서 거의 직선처럼 예측 가능하게 감소한다는 뜻이다. 다만 규모를 2배로 키워도 성능 향상은 점점 작아지는 수확 체감이 있다.
Chinchilla law: compute가 정해져 있을 때 가장 큰 모델을 고르는 법칙이 아니라, loss를 최소화하는 N-D 비율을 고르는 법칙이다. 핵심 결론은 “모델만 크게 만들지 말고, 파라미터 수에 맞게 학습 토큰 수도 같이 늘려야 한다”이다.

① Alignment 필요성 & HHH▼
★★유력 왜 Alignment가 필요한가

② Bradley-Terry & RLHF Alignment▼
★★★반드시 출제 Bradley-Terry 모델
P(y_w ≻ y_l) = σ(r_w - r_l) = e^r_w / (e^r_w + e^r_l)
// y_w=선호 응답, y_l=비선호, r=reward score
예: r_w=3.0, r_l=1.0 → P = e³/(e³+e¹) ≈ 0.881
  • Pairwise 비교가 절대 점수(1~10)보다 인간 판단이 더 일관적
★★유력 KL Penalty — Alignment 안전장치
J(θ) = E[r(y)] - β × KL(π_θ || π_ref)
// reward 극대화 + reference policy 이탈 제한
  • Reward Hacking: 보상 모델의 허점을 파고드는 현상
  • Mode Collapse: 응답 다양성 감소, 특정 패턴으로 수렴
  • KL penalty가 두 가지 모두 완화 (β 클수록 reference에 가깝게 유지)

② Sparse vs Dense Retrieval▼
★★★반드시 출제 TF-IDF (Sparse)
TF(t,d) = log(1 + freq(t,d))
IDF(t) = log( N / DF(t) )
TF-IDF = TF × IDF
// N=전체 문서 수, DF=단어 t 포함 문서 수
  • 흔한 단어(good, the) → DF 크면 IDF≈0 → 변별력 없음

★★★반드시 출제 Precision / Recall / AP
Precision@k = |top-k 중 관련| / k // 결과의 순수도
Recall@k = |top-k 중 관련| / |전체 관련| // 전체 회수율
AP = (1/|관련|) × Σ P@k × I(d_k 관련)
💡 암기 팁: Precision = Purity (순수도), Recall = Retrieval rate (회수율)

  • [Pre] LoRA: ΔW = BA, B∈R^(d×r), A∈R^(r×d), 파라미터 절감 = d/(2r)
  • [Pre→RAG] Parametric 지식은 Pre-training에서 형성, Non-parametric은 RAG 추론 시 보완
  • [Post] Post-training 순서: SFT(Instruction Tuning) → RLHF 또는 RLVR
  • [Post] RLHF와 RLVR는 형제 관계 (RLVR가 RLHF 하위 아님)
  • [Post] GRPO: PPO 변형, Critic 없이 Group-relative advantage 사용
  • [Rea] ICL = 추론 단계, 파라미터 업데이트 없음. Instruction Tuning = 학습 단계, 파라미터 업데이트 있음
  • [Rea] CoT는 zero-shot/few-shot 둘 다 가능. Self-consistency는 여러 CoT path 생성 후 최종 답 다수결
  • [Rea] Test-time Scaling = 추론 시 compute 증가 (학습 compute 아님)
  • [Rea/RAG] RAG-Token은 CoT를 시작시키는 기술이 아니라 토큰별 문서 조건화 방식
  • [Ali] Bradley-Terry: P(y_w≻y_l) = σ(r_w - r_l)
  • [Ali] RL의 state는 현재 문맥, policy는 LLM, action은 생성 응답, reward는 인간 선호 또는 verifier 점수
  • [Ali] KL penalty: J(θ) = E[r(y)] - β·KL. Reward hacking + Mode collapse 방지
  • [RAG] Precision@k = top-k 중 관련 / k. Recall@k = top-k 중 관련 / 전체 관련
  • [RAG] Bi-encoder = 빠른 1단계 검색. Cross-encoder = 정밀 2단계 재랭킹
  • [RAG] TF-IDF: 흔한 단어 → IDF≈0 → 변별력 없음
자주 혼동 — 시험에서 틀리기 쉬운 것
  • ICL은 Reasoning 단계 (추론 시 프롬프트). Post-training 아님
  • Instruction Tuning은 Post-training 1단계 (SFT). ICL과 대체 관계 아님
  • RLVR는 RLHF의 종류가 아님 — 둘 다 Post-training RL 계열의 형제
  • Test-time Scaling ≠ Training-time Scaling. 추론 시 compute 증가 vs 모델 크기 증가
  • Parametric knowledge = Pre-training 결과. RAG는 이걸 대체하는 게 아니라 보완
  • CoT는 대형 모델에서 효과. 소형 모델에서는 오히려 성능 저하 가능
  • GSM8K = 8.5K (초등 수학), MATH = 12.5K (경쟁 수학). 수치 혼동 주의
  • RAG-Token ≠ RAG-Sequence. Token = 토큰마다 다른 문서, Sequence = 전체에 동일 문서
  • Prompt Tuning = soft prompt 벡터 학습 (자연어 프롬프트 수정 아님)
  • Alignment = 내부 생각을 인간과 같게 만드는 것이 아니라 출력 행동을 HHH 기준에 맞추는 것
  • LLaVA projection은 LoRA식 low-rank update가 아님. LoRA는 PEFT, LLaVA는 multimodal architecture
  • Sigmoid는 Bradley-Terry 선호 확률, Softmax는 다음 토큰 확률분포와 연결
  • GRPO = Critic 없음. PPO = Critic 있음 (Value network)
