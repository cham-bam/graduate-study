핵심 구분표: Prompting · ICL · RAG · Tuning

ICL/RAG/Prompt engineering은 추론 시점에 입력을 구성하는 방법이고, Instruction tuning/Soft prompt tuning/LoRA는 학습 시점에 일부 파라미터를 업데이트하는 방법이다.
개념언제 일어남무엇을 바꾸나핵심 의미
Prompt engineering 추론 시점 자연어 프롬프트 사람이 지시문, 역할, 출력 형식, 예시 배치를 직접 설계한다. 학습은 일어나지 않는다.
ICL / Few-shot prompting 추론 시점 프롬프트 안 예시 모델 파라미터 업데이트 없이, 문맥에 포함된 입출력 예시를 보고 그 자리에서 패턴을 따라간다.
RAG 추론 시점 검색된 외부 문서 질문과 관련된 문서를 검색해 context에 붙인다. ICL의 상위 개념이 아니라 검색으로 문맥을 보강하는 별도 기법이다.
Instruction tuning 학습 시점 모델 파라미터 instruction-response 데이터로 supervised fine-tuning하여 지시 따르기 능력을 모델에 지속적으로 반영한다.
Soft prompt tuning 학습 시점 학습 가능한 soft prompt 벡터 자연어 프롬프트를 고치는 것이 아니라, 입력 임베딩 앞에 붙는 연속 벡터만 gradient로 최적화한다. PEFT의 일종이다.
LoRA 학습 시점 저랭크 업데이트 행렬 A, B 기존 가중치 W는 고정하고 ΔW≈BA만 학습한다. 큰 모델을 싸게 특정 태스크에 맞추는 PEFT 방식이다.
Tool use / Agent 추론 시점 중심 도구 호출, 메모리, 행동 루프 LLM이 검색, API, 코드 실행 같은 외부 도구를 호출하고 관찰 결과를 다시 반영한다.
시험 답안 포인트: "ICL은 prompt engineering으로 끌어낼 수 있는 현상", "RAG는 ICL의 상위 개념이 아님", "soft prompt tuning은 자연어 수정이 아니라 벡터 학습", "instruction tuning은 fine-tuning의 한 종류"로 정리하면 된다.

6~9강 전체 맥락: 모델 개발에서 추론·에이전트까지

6강은 모델을 만들고 싸게 적응시키는 방법, 7강은 외부 지식으로 보완하는 방법, 8강은 더 잘 추론하고 정렬하는 방법, 9강은 선호·도구·멀티모달·에이전트로 확장하는 흐름이다.
흐름핵심 개념시험 포인트
Pre-training 다음 토큰 예측, parametric knowledge, scaling law, emergent ability 지식은 모델 파라미터 안에 저장된다. State가 사전학습 지식이라는 뜻은 아니다.
PEFT / 적응 LoRA, soft prompt tuning, instruction tuning LoRA와 soft prompt tuning은 학습 시점 기법이다. 자연어 프롬프트 수정과 구분한다.
Inference / Reasoning Prompt engineering, ICL, CoT, self-consistency, test-time scaling ICL은 파라미터 업데이트가 없고, CoT는 zero-shot/few-shot 둘 다 가능하다.
RAG Non-parametric knowledge, sparse/dense retrieval, RAG-Sequence/Token RAG는 ICL의 상위 개념이 아니라 검색 문서를 context에 붙이는 지식 보강 기법이다.
Post-training / Alignment RLHF, RLVR, reward model, Bradley-Terry, KL penalty Alignment는 인간과 모델의 생각을 같게 만드는 것이 아니라 출력 행동을 HHH 기준에 맞추는 것이다.
Agents Toolformer, LLaVA, SWE-Bench, observe-reason-act loop Agent는 단발 답변이 아니라 도구 호출과 관찰을 반복하는 시스템이다.

자주 질문한 개념 매칭표

헷갈리는 질문정확한 매칭
RL의 state가 사전학습 지식인가?아니다. State는 현재 prompt, 대화 기록, 지금까지 생성한 토큰이다. 사전학습 지식은 policy model의 파라미터 안에 있다.
RL은 top-p 후보 토큰 보상을 조절하나?아니다. Sampling으로 생성된 응답/토큰 경로에 reward를 주고, 그 경로의 log probability가 커지거나 작아지도록 policy를 업데이트한다.
RLHF에서 pairwise란?같은 prompt에 대한 두 응답 중 더 나은 것을 고르는 선호 데이터다. Bradley-Terry는 reward 차이를 sigmoid로 선호 확률화한다.
RLVR의 verifier는 대형 모델인가?꼭 아니다. 정답 비교기, unit test, 규칙 기반 checker일 수 있고, 경우에 따라 LLM judge를 쓸 수도 있다.
RAG-Token이 CoT를 시작시키나?아니다. RAG-Token은 문서 조건화 방식이고, CoT는 단계적 추론을 유도하는 프롬프팅/추론 방식이다. 둘은 결합 가능하지만 독립 개념이다.
Emergent ability와 Aha moment는 같은가?아니다. Emergent ability는 규모 증가에 따른 능력 출현이고, Aha moment는 RL post-training 중 자기검토 같은 추론 전략이 나타나는 현상이다.
LoRA와 LLaVA는 둘 다 low-rank인가?LoRA는 low-rank update가 핵심이다. LLaVA는 CLIP feature를 LLM embedding 공간으로 projection하는 멀티모달 구조이며, projection이 곧 LoRA라는 뜻은 아니다.
Sigmoid와 Softmax는 언제 쓰나?Sigmoid는 하나의 점수나 reward 차이를 0~1로 바꾼다. Softmax는 여러 후보 점수를 합 1인 확률분포로 만든다.

[Example 6-1] LoRA Parameter Reduction
LoRA 파라미터 절감량 계산
문제: 사전학습된 weight matrix W₀ ∈ ℝ768×768에 LoRA를 적용할 때 (rank r=8),
원본 파라미터 수와 LoRA (B, A) 파라미터 수를 각각 구하고, 절감 배율을 계산하라.
단계별 풀이:
• 원본 행렬: 768 × 768 = 589,824 파라미터
• LoRA 분해: B ∈ ℝ768×8, A ∈ ℝ8×768
→ B: 768×8 = 6,144   A: 8×768 = 6,144   합계: 12,288
• 절감 배율: 589,824 / 12,288 = 48배 (97.9% 감소)
• 공식: 절감 배율 = d / (2r) = 768 / (2×8) = 48
상세 설명: LoRA는 사전학습된 가중치 W₀를 frozen 상태로 유지하면서, 업데이트 행렬 ΔW를 두 저랭크 행렬의 곱 BA로 근사합니다. 순전파: h = W₀x + ΔWx = W₀x + BAx. 원래 d×d 행렬 업데이트에 d² 파라미터가 필요하지만, ΔW ≈ BA (B∈ℝd×r, A∈ℝr×d)로 표현하면 2dr 개만 필요합니다. r≪d 조건 덕분에 파라미터가 극적으로 줄어듭니다. 실제로 Attention의 Q, V 행렬에 주로 적용하며, 대형 모델의 가중치 업데이트가 본질적으로 저랭크 구조를 가진다는 경험적 관찰에 기반합니다.
핵심: 절감 배율 = d/(2r). ΔW = BA. W₀는 frozen.
[연습 6-1-A]
W ∈ ℝ512×512에 LoRA(r=4)를 적용할 때, 원본 파라미터 수, LoRA 파라미터 수, 절감 배율을 구하라.
• 원본: 512 × 512 = 262,144
• LoRA: 512×4 + 4×512 = 2,048 + 2,048 = 4,096
• 절감 배율: 262,144 / 4,096 = 64배  (d/(2r) = 512/8 = 64)
[연습 6-1-B]
W ∈ ℝ1024×1024에 LoRA(r=32)를 적용할 때, LoRA 파라미터 수와 절감 배율을 구하라.
• 원본: 1,024 × 1,024 = 1,048,576
• LoRA: 1024×32 + 32×1024 = 32,768 + 32,768 = 65,536
• 절감 배율: 1,048,576 / 65,536 = 16배  (d/(2r) = 1024/64 = 16)
[Example 6-2] Scaling Laws: Language Model Loss
스케일링 법칙으로 모델 손실값 계산
문제: Scaling law L(N) = (Nc/N)αN에서 αN = 0.076, Nc = 8.8×1013일 때,
N = 109 (1B 파라미터)인 경우 L(N)을 계산하라.
단계별 풀이:
• L(N) = (8.8×1013 / 109)0.076 = (8.8×104)0.076
• log₁₀(88,000) ≈ 4.944
• 0.076 × 4.944 ≈ 0.376
• L(N) ≈ 100.376 ≈ 2.38
상세 설명: 스케일링 법칙(Scaling Laws)은 모델 성능(Cross-Entropy Loss)이 모델 파라미터 수(N), 데이터양(D), 컴퓨팅(C=FLOPs) 각각과 멱법칙(power-law) 관계를 가진다는 실험적 발견입니다. 공식 L(N) = (Nc/N)αN에서 Nc는 임계 모델 크기, αN은 지수(실험적으로 측정). N이 클수록 L이 줄어드는(성능 향상) 패턴이 성립합니다.
계산 요령: ① (Nc/N) 비율 계산 → ② log₁₀으로 변환 → ③ αN을 곱해 지수 → ④ 10의 거듭제곱으로 환원. 이 공식으로 특정 손실 목표 달성에 필요한 모델 크기를 사전에 예측할 수 있어 대형 모델 훈련 비용 최적화에 활용됩니다.
핵심: 계산 순서 — 비율 → log₁₀ → ×αN → 10^결과. N 클수록 L 작아짐.
[연습 6-2-A]
동일 조건(αN=0.076, Nc=8.8×1013)에서 N=1010 (10B 파라미터)일 때 L(N)을 구하라.
• (8.8×1013 / 1010)0.076 = (8,800)0.076
• log₁₀(8,800) ≈ 3.944
• 0.076 × 3.944 ≈ 0.300
• L(10B) ≈ 100.300 ≈ 2.00
💡 N이 10배 증가(1B→10B)할수록 손실이 2.38→2.00으로 감소.
[연습 6-2-B]
동일 조건에서 N=1011 (100B 파라미터)일 때 L(N)을 구하라.
• (8.8×1013 / 1011)0.076 = (880)0.076
• log₁₀(880) ≈ 2.944
• 0.076 × 2.944 ≈ 0.224
• L(100B) ≈ 100.224 ≈ 1.67
💡 1B→10B→100B 손실: 2.38→2.00→1.67 (모델 클수록 손실 줄어듦)
[Example 6-3] Temperature Sampling: Probability Reshaping
온도 샘플링: 확률 분포 변환
문제: 다음 토큰 확률이 P(A)=0.5, P(B)=0.3, P(C)=0.2일 때, 온도 τ=2를 적용한 후의 새로운 확률 분포를 구하라.
단계별 풀이: 각 확률에 1/τ 제곱 후 재정규화
• P(A)1/2 = 0.50.5 = 0.707
• P(B)1/2 = 0.30.5 = 0.548
• P(C)1/2 = 0.20.5 = 0.447
• 합계: 0.707 + 0.548 + 0.447 = 1.702
• 정규화: P(A) = 0.707/1.702 ≈ 0.416, P(B) ≈ 0.322, P(C) ≈ 0.263
상세 설명: 온도(τ)는 토큰 확률 분포의 뾰족함을 조절합니다. 원리: 원본 로짓(logit)을 τ로 나눈 후 softmax 적용 = 확률에 1/τ 거듭제곱 후 재정규화와 동일.
• τ < 1 → 높은 확률 토큰의 비중이 더 증가 → 분포가 더 뾰족해짐(보수적 생성)
• τ > 1 → 확률 차이가 줄어들어 분포가 평탄해짐(다양성 증가) ← 이 예제 (τ=2)
• τ → 0 → greedy decoding(가장 높은 확률 토큰만)
• τ → ∞ → 모든 토큰 동일 확률(완전 랜덤)
원본 P(A)=0.5였지만 τ=2 적용 후 0.416으로 낮아지고, P(C)=0.2였다가 0.263으로 올라간 것을 확인하세요. 다양성이 증가했습니다.
핵심: τ>1 → 평탄(다양성↑). τ<1 → 뾰족(집중↑). τ→0 = greedy.
[연습 6-3-A]
P(A)=0.6, P(B)=0.3, P(C)=0.1일 때, τ=0.5를 적용한 후의 확률 분포를 구하라. (τ<1 효과 확인)
• 1/τ = 1/0.5 = 2
• P(A)2 = 0.6² = 0.360
• P(B)2 = 0.3² = 0.090
• P(C)2 = 0.1² = 0.010
• 합계: 0.360 + 0.090 + 0.010 = 0.460
• 정규화: P(A) = 0.360/0.460 ≈ 0.783, P(B) ≈ 0.196, P(C) ≈ 0.022
💡 τ<1이므로 P(A)가 0.6→0.783으로 올라가고 P(C)는 0.1→0.022로 감소. 분포가 더 뾰족해짐.
[연습 6-3-B]
P(A)=0.4, P(B)=0.35, P(C)=0.25일 때, τ=3을 적용한 후의 확률 분포를 구하라. (소수점 3자리)
• 1/τ = 1/3 ≈ 0.333
• P(A)0.333 = 0.41/3 ≈ 0.737
• P(B)0.333 = 0.351/3 ≈ 0.705
• P(C)0.333 = 0.251/3 ≈ 0.630
• 합계: 0.737 + 0.705 + 0.630 = 2.072
• 정규화: P(A) ≈ 0.356, P(B) ≈ 0.340, P(C) ≈ 0.304
💡 τ=3(큰 값)이므로 0.4:0.35:0.25가 0.356:0.340:0.304로 거의 균등해짐.

7강: Retrieval-Augmented Generation (RAG)

[Example 7-1] IDF Calculation (Shakespeare Corpus)
IDF 계산: Shakespeare 코퍼스 예제 (슬라이드 직접 출제)
문제: 총 37개 문서로 구성된 Shakespeare 코퍼스에서 다음 단어의 IDF를 계산하라.
(a) "Romeo" (DF=1)   (b) "forest" (DF=12)   (c) "good" (DF=37)   IDF = log₁₀(N/DF)
단계별 풀이:
• IDF("Romeo") = log₁₀(37/1) = log₁₀(37) ≈ 1.57 → 희귀 단어, 높은 변별력
• IDF("forest") = log₁₀(37/12) = log₁₀(3.083) ≈ 0.49 → 중간 변별력
• IDF("good") = log₁₀(37/37) = log₁₀(1) = 0 → 전체 등장, 변별력 없음
상세 설명: IDF(Inverse Document Frequency)는 특정 단어가 얼마나 '변별력'을 가지는지 측정합니다. 공식: IDF(t) = log₁₀(N/DF(t)). N=전체 문서 수, DF=해당 단어가 등장하는 문서 수.
• DF가 작을수록(희귀 단어) → N/DF 큰 수 → log 값 큼 → 변별력 높음
• DF=N이면 → log(1)=0 → 변별력 없음 ("the", "a", "good" 같은 불용어)
TF-IDF = TF(해당 문서에서 등장 빈도) × IDF(전체 문서 기준 희귀도). "Romeo"는 특정 문서에만 등장하므로 TF-IDF가 높아져 해당 문서를 찾는 데 유용합니다. 슬라이드 예제로 직접 출제될 가능성 높음.
핵심: DF=N → IDF=0. DF 작을수록 IDF 큼. TF-IDF = TF × IDF.
[연습 7-1-A]
총 100개 문서에서 IDF = log₁₀(N/DF)로 계산하라.
(a) "Python" (DF=5)   (b) "the" (DF=100)   (c) "algorithm" (DF=20)
• IDF("Python") = log₁₀(100/5) = log₁₀(20) ≈ 1.301
• IDF("the") = log₁₀(100/100) = log₁₀(1) = 0
• IDF("algorithm") = log₁₀(100/20) = log₁₀(5) ≈ 0.699
[연습 7-1-B]
총 50개 문서에서 IDF를 계산하라.
(a) "neural" (DF=10)   (b) "transformer" (DF=2)   (c) "is" (DF=50)
• IDF("neural") = log₁₀(50/10) = log₁₀(5) ≈ 0.699
• IDF("transformer") = log₁₀(50/2) = log₁₀(25) ≈ 1.398
• IDF("is") = log₁₀(50/50) = 0
[Example 7-2] Precision & Recall @k
검색 평가: Precision & Recall @k 계산
문제: 전체 관련 문서(U)가 9개인 컬렉션에서 검색 시스템이 순위 리스트를 반환했다.
1위, 2위, 4위, 6위, 8위가 관련 문서(relevant)이다. (a) P@3, R@3   (b) P@5, R@5를 계산하라.
단계별 풀이:
• Top-3 중 관련: 1위✓, 2위✓, 3위✗ → |R|=2, |T|=3
P@3 = 2/3 ≈ 0.667    R@3 = 2/9 ≈ 0.222
• Top-5 중 관련: 1위✓, 2위✓, 3위✗, 4위✓, 5위✗ → |R|=3, |T|=5
P@5 = 3/5 = 0.600    R@5 = 3/9 ≈ 0.333
상세 설명: 정보 검색 평가의 핵심 지표입니다.
• |T| = 검색된 문서 수 (Top-k이면 k)
• |U| = 전체 컬렉션의 실제 관련 문서 수 (이 예제에서 9개)
• |R| = 검색 결과(Top-k) 중 실제 관련 문서 수
• Precision@k = |R|/|T| = k개 결과 중 관련 문서 비율 → "얼마나 정확하게 찾았나"
• Recall@k = |R|/|U| = 전체 관련 문서 중 찾은 비율 → "얼마나 많이 찾았나"
k가 커질수록 일반적으로 Recall↑ (더 많이 찾음), Precision↓ (무관 문서 섞임). 두 지표는 트레이드오프 관계.
핵심: Precision=|R|/|T|(검색결과 기준), Recall=|R|/|U|(전체관련 기준). 혼동 금지!
[연습 7-2-A]
전체 관련 문서(U)=12. 검색 결과에서 1위, 3위, 5위, 7위, 9위가 관련 문서일 때,
(a) P@4, R@4   (b) P@6, R@6을 구하라.
• Top-4 관련: 1위✓, 2위✗, 3위✓, 4위✗ → |R|=2
P@4 = 2/4 = 0.500    R@4 = 2/12 ≈ 0.167
• Top-6 관련: 1위✓, 3위✓, 5위✓ → |R|=3
P@6 = 3/6 = 0.500    R@6 = 3/12 = 0.250
[연습 7-2-B]
전체 관련 문서(U)=10. 검색 결과에서 2위, 3위, 6위, 9위가 관련 문서일 때,
(a) P@5, R@5   (b) P@10, R@10을 구하라.
• Top-5 관련: 2위✓, 3위✓ → |R|=2
P@5 = 2/5 = 0.400    R@5 = 2/10 = 0.200
• Top-10 관련: 2위✓, 3위✓, 6위✓, 9위✓ → |R|=4
P@10 = 4/10 = 0.400    R@10 = 4/10 = 0.400
[Example 7-3] Average Precision (AP) Calculation
평균 정밀도(AP) 계산
문제: 검색 결과 5개 중 2번째, 4번째 문서만 관련(relevant)일 때 AP를 계산하라.
AP = (1/|R|) × Σ (P@k × I(d_k is relevant))
단계별 풀이:
• |R| = 2 (관련 문서 총 2개)
• k=1: 관련✗ → 기여 없음
• k=2: 관련✓ → P@2 = 1/2 = 0.500 → 기여 +0.500
• k=3: 관련✗ → 기여 없음
• k=4: 관련✓ → P@4 = 2/4 = 0.500 → 기여 +0.500
• k=5: 관련✗ → 기여 없음
• AP = (1/2) × (0.500 + 0.500) = 0.50
상세 설명: AP(Average Precision)는 검색 순위 리스트 전체를 평가하는 지표입니다. 핵심 아이디어: 관련 문서가 상위 순위에 있을수록 AP가 높아집니다.
계산 방법: ① 관련 문서가 검색될 때마다 그 시점의 Precision@k를 기록 → ② 그 값들의 평균. I(dk is relevant)는 k번째 문서가 관련이면 1, 아니면 0.
예를 들어 관련 문서가 2위, 4위에 있으면 P@2=0.5, P@4=0.5 → AP=0.5. 만약 관련 문서가 1위, 2위에 있었다면 P@1=1.0, P@2=1.0 → AP=1.0 (최고). 관련 문서를 최대한 앞 순위에 배치할수록 좋습니다.
핵심: 관련 문서 순위마다 P@k를 기록 → 평균. 앞 순위 관련일수록 AP 높음.
[연습 7-3-A]
검색 결과 5개 중 1번째, 3번째, 5번째 문서가 관련일 때 AP를 계산하라.
• |R| = 3
• k=1: 관련✓ → P@1 = 1/1 = 1.000
• k=3: 관련✓ → P@3 = 2/3 ≈ 0.667
• k=5: 관련✓ → P@5 = 3/5 = 0.600
• AP = (1/3) × (1.000 + 0.667 + 0.600) = (1/3) × 2.267 ≈ 0.756
💡 1위에 관련 문서가 있어 AP=0.756 > 원래 예제 0.50. 상위 배치 효과 확인.
[연습 7-3-B]
검색 결과 6개 중 3번째, 5번째만 관련일 때 AP를 계산하라.
• |R| = 2
• k=3: 관련✓ → P@3 = 1/3 ≈ 0.333
• k=5: 관련✓ → P@5 = 2/5 = 0.400
• AP = (1/2) × (0.333 + 0.400) = (1/2) × 0.733 ≈ 0.367
💡 원 예제(2위,4위)와 비교: AP 0.50 > 0.367. 더 낮은 순위에 관련 문서가 있으면 AP 낮아짐.

[Example 8-1] Self-consistency CoT: Majority Voting
Self-consistency CoT: 다수결 투표
문제: "3개 사과가 $6이면 5개 사과는?" 질문에 모델을 온도 샘플링으로 5번 실행했을 때
결과: $10, $10, $8, $10, $12. Self-consistency 방법으로 최종 답을 선택하라.
단계별 풀이:
• $10: 3번 등장 ← 최다
• $8: 1번 등장
• $12: 1번 등장
• Majority Vote → 최종 답: $10
※ 실제 정답: 5개 × ($6/3개) = 5 × $2 = $10 ✓
상세 설명: Self-consistency CoT는 단일 추론 경로의 취약성을 해결합니다. 단일 CoT는 중간 단계 하나만 틀려도 최종 오답이 되지만, Self-consistency는 온도 샘플링(τ>0)으로 다양한 추론 경로를 여러 번 생성한 뒤 다수결 투표로 최종 답을 선택합니다.
핵심 가정: 올바른 추론 경로들은 일관된 답에 수렴하고, 잘못된 경로들은 다양한 오답으로 분산됩니다. 따라서 가장 많이 등장한 답이 정답일 가능성이 높습니다. N회 호출(계산 비용 증가)이 단점이지만 정확도가 크게 향상됩니다.
핵심: 여러 추론 경로 생성 → Majority Vote. 올바른 경로 = 같은 답에 수렴.
[연습 8-1-A]
"12명을 3팀으로 나누면 한 팀은?" 질문에 7번 샘플링 결과: 4, 4, 3, 4, 5, 4, 3. 최종 답은?
• 4: 4번 등장 ← 최다
• 3: 2번 등장
• 5: 1번 등장
• Majority Vote → 최종 답: 4명 (실제 정답: 12/3=4 ✓)
[연습 8-1-B]
번역 태스크에서 6번 샘플링 결과: "파리", "파리", "런던", "파리", "베를린", "파리". 최종 답은? 이 방식의 한계를 서술하라.
• "파리": 4번 → 최종 답: 파리
• 한계: Self-consistency는 단일 정답(Closed-ended) 문제에 효과적. 창의적/개방형 생성(Open-ended)에서는 "최다 등장 답"의 의미가 불분명해짐. 계산 비용이 N배로 증가하는 단점도 있음.
[Example 8-2] RLVR Expected Reward (REINFORCE)
RLVR 기대 보상 계산 (REINFORCE)
문제: RLVR에서 모델의 정답률 60%. 이진 보상: 정답 r=1, 오답 r=0.
(a) 현재 E[r]를 계산하라.   (b) 학습 후 정답률 80%일 때 E[r]은?
단계별 풀이:
• (a) E[r] = 0.6 × 1 + 0.4 × 0 = 0.6
• (b) E[r] = 0.8 × 1 + 0.2 × 0 = 0.8
상세 설명: RLVR(RL with Verifiable Rewards)에서 기대 보상 E[r]은 모델의 현재 능력을 수치로 나타냅니다. 이진 보상(Binary Reward): 검증 가능한 정답이면 r=1, 오답이면 r=0.
REINFORCE 업데이트 규칙: ∇J(θ) = E[r × ∇log π_θ(y|x)]. 보상이 높을수록(r=1) 해당 생성 경로의 log-probability를 높이도록 파라미터를 조정합니다. 오답(r=0)에서는 기울기 기여가 없어 업데이트 없음. 이진 보상이므로 E[r] = 정답률 그 자체입니다.
RLVR의 장점: 자동 검증기(verifier)로 인간 개입 없이 이진 보상 부여 가능 → 데이터 확장성 우수.
핵심: 이진 보상에서 E[r] = 정답률. REINFORCE: r=1이면 해당 경로 log-prob↑.
[연습 8-2-A]
이진 보상(r=1/0)에서 정답률 45%일 때 E[r]을 구하라. 학습 후 75%가 되면 E[r]은?
• 초기: E[r] = 0.45×1 + 0.55×0 = 0.45
• 학습 후: E[r] = 0.75×1 + 0.25×0 = 0.75
[연습 8-2-B]
보상이 정답 r=+2, 오답 r=−1인 경우, 정답률 60%일 때 E[r]은? 학습 후 80%일 때는?
• 초기: E[r] = 0.6×(+2) + 0.4×(−1) = 1.2 − 0.4 = 0.8
• 학습 후: E[r] = 0.8×(+2) + 0.2×(−1) = 1.6 − 0.2 = 1.4
💡 비이진 보상에서는 E[r] ≠ 정답률. E[r] = Σ (확률 × 보상)

[Example 9-1] Bradley-Terry Reward Model
RLHF 보상 모델: Bradley-Terry 선호 확률 계산
문제: r_w = 3.0 (선호 응답), r_l = 1.0 (비선호 응답)일 때
Bradley-Terry 모델로 P(y_w ≻ y_l) = er_w / (er_w + er_l)을 계산하라.
단계별 풀이:
• e3.0 ≈ 20.09,   e1.0 ≈ 2.718
• P = 20.09 / (20.09 + 2.718) = 20.09 / 22.808 ≈ 0.881 (88.1%)
• 또는: P = σ(r_w − r_l) = σ(3.0 − 1.0) = σ(2.0) ≈ 0.881
상세 설명: Bradley-Terry 모델은 두 항목 간 선호 확률을 모델링합니다. P(A≻B) = erA/(erA+erB) = σ(rA−rB). σ는 시그모이드 함수.
핵심 특성: ① r_w=r_l이면 P=0.5(무차별). ② 차이(r_w−r_l)가 클수록 P→1. ③ σ(2.0)≈0.881은 자주 출제되는 수치이므로 기억 권장.
RLHF에서 이 목적함수로 인간 선호 쌍 데이터(y_w≻y_l)를 사용해 보상 모델을 학습합니다. 학습 손실: L = −E[log P(y_w≻y_l)] = −E[log σ(r_w−r_l)].
핵심: P = erw/(erw+erl) = σ(rw−rl). 차이 2.0 → P≈88.1%.
[연습 9-1-A]
r_w = 2.0, r_l = 0.5일 때 P(y_w ≻ y_l)를 계산하라. (e2.0≈7.389, e0.5≈1.649)
• P = 7.389 / (7.389 + 1.649) = 7.389 / 9.038 ≈ 0.817 (81.7%)
• 또는 σ(2.0−0.5) = σ(1.5) ≈ 0.817
💡 차이가 2.0→1.5로 줄었으므로 P도 88.1%→81.7%로 감소.
[연습 9-1-B]
r_w = 5.0, r_l = 3.0일 때 P(y_w ≻ y_l)를 구하라. (e5≈148.4, e3≈20.09)
• P = 148.4 / (148.4 + 20.09) = 148.4 / 168.49 ≈ 0.881 (88.1%)
• σ(5.0−3.0) = σ(2.0) ≈ 0.881 ← 원 예제와 동일!
💡 절대값 r_w, r_l이 달라도 차이(r_w−r_l)가 같으면 P가 같음. 중요한 성질!
[Example 9-2] RLHF: KL Divergence Regularization
RLHF: KL 발산 패널티 계산
문제: J(θ) = E[r(y)] − β × KL(π_θ || π_ref)
E[r]=2.5, KL=1.2, β=0.3일 때 J(θ)를 구하라.
단계별 풀이:
• KL 패널티: β × KL = 0.3 × 1.2 = 0.36
• J(θ) = 2.5 − 0.36 = 2.14
상세 설명: RLHF의 regularized objective는 순수 보상 최대화의 문제점(reward hacking, mode collapse 등)을 해결합니다.
• E[r(y)]: 현재 정책 모델의 기대 보상 (높을수록 좋음)
• KL(π_θ ∥ π_ref): 현재 정책이 참조 SFT 모델에서 얼마나 벗어났는지 (작을수록 좋음)
• β: KL 패널티 강도. β=0이면 순수 reward 최대화 → reward hacking 위험. β가 클수록 참조 모델에 가깝게 유지.
J(θ)를 최대화하는 것 = "보상을 높이되, 참조 모델에서 너무 멀리 벗어나지 말 것"의 균형.
핵심: J = E[r] − β×KL. β↑ → 참조 모델 이탈 억제. β=0 → reward hacking 위험.
[연습 9-2-A]
E[r]=3.0, KL=0.8, β=0.5일 때 J(θ)를 구하라.
• KL 패널티: 0.5 × 0.8 = 0.40
• J(θ) = 3.0 − 0.40 = 2.60
[연습 9-2-B]
E[r]=4.2, KL=2.0일 때, (a) β=0.1이면 J=? (b) β=1.0이면 J=? β 크기 변화의 의미를 설명하라.
• (a) β=0.1: J = 4.2 − 0.1×2.0 = 4.2 − 0.20 = 4.00
• (b) β=1.0: J = 4.2 − 1.0×2.0 = 4.2 − 2.00 = 2.20
• β가 0.1→1.0으로 10배 증가하면, KL 이탈(2.0)이 강하게 패널티되어 J가 4.00→2.20으로 감소. β가 클수록 참조 모델 근처에서 최적화해야 함.
[Example 9-3] LLaVA Projection Matrix Size
LLaVA: 시각-텍스트 프로젝션 행렬 파라미터 수
문제: LLaVA에서 CLIP 출력 768-dim, LLM 입력 4096-dim일 때, 프로젝션 행렬 W의 파라미터 수는?
단계별 풀이:
• W ∈ ℝ768×4096 (CLIP dim → LLM dim)
• 파라미터 수: 768 × 4096 = 3,145,728 ≈ 3.1M
상세 설명: LLaVA(Large Language and Vision Assistant) 아키텍처:
① CLIP 비전 인코더: 이미지 패치 → Z_v (각 패치에 768-dim 벡터)
② 프로젝션: H_v = W × Z_v (768-dim → 4096-dim, 언어 공간으로 변환)
③ Concatenate: [H_v; H_q] (시각 토큰 + 텍스트 토큰) → LLaMA 입력
학습 단계: 초기에 CLIP 인코더·LLaMA 모두 frozen, W만 학습 → 이후 전체 fine-tuning. W를 통해 "이미지 토큰"이 텍스트 토큰과 동일한 공간에서 처리됩니다.
핵심: W 크기 = CLIP_dim × LLM_dim. H_v=W×Z_v → [H_v;H_q] → LLM.
[연습 9-3-A]
CLIP 출력 1024-dim, LLM 입력 4096-dim인 LLaVA 변형에서 W의 파라미터 수는?
• W ∈ ℝ1024×4096
• 파라미터 수: 1024 × 4096 = 4,194,304 ≈ 4.2M
[연습 9-3-B]
CLIP 출력 512-dim, LLM 입력 2048-dim일 때 W의 파라미터 수는? 원 예제(768→4096, 3.1M)와 비교 설명하라.
• W ∈ ℝ512×2048
• 파라미터 수: 512 × 2048 = 1,048,576 ≈ 1.05M
• 원 예제 3.1M 대비 약 1/3 수준. 더 작은 모델(소형 LLM)일수록 W도 작아짐.

PART 2: True / False 문제

6강: LLMs & In-context Learning

Q1 T/F LoRA는 weight update ΔW를 저랭크(low-rank) 행렬의 곱 BA로 근사한다.
TRUE — ΔW ≈ BA (B∈ℝd×r, A∈ℝr×d, r≪d). 사전학습 가중치 W₀는 frozen.
Q2 T/F In-context learning은 모델 파라미터를 업데이트하여 새 작업에 적응한다.
FALSE — ICL은 파라미터 업데이트 없음. 프롬프트의 예제로만 학습 효과를 냄. GPT-3 논문에서 처음 연구.
Q3 T/F k=1인 Top-k sampling은 greedy decoding과 동일하다.
TRUE — k=1이면 가장 높은 확률의 토큰만 선택 → greedy decoding과 동일.
Q4 T/F Emergent ability는 소규모 모델의 성능으로 사전에 예측할 수 있다.
FALSE — Emergent ability는 특정 규모 임계값 이전까지 random 성능을 보이다 갑자기 나타남. 소규모 모델로 예측 불가.
Q5 T/F Prompt tuning에서는 LM 파라미터 전체를 학습한다.
FALSE — Prompt tuning은 LM을 frozen한 채 소수의 prompt token embedding만 학습. PEFT의 일종.
Q6 T/F GPT-3는 96개 레이어, 175B 파라미터를 가지며 2020년에 공개되었다.
TRUE — 슬라이드 직접 인용: GPT-3(2020): 96 layers, 175B parameters.
Q7 T/F 온도 τ→∞일 때 temperature sampling은 greedy decoding에 가까워진다.
FALSE — τ→0이 greedy decoding에 수렴. τ→∞는 모든 토큰이 균등 확률이 되어 완전 랜덤 샘플링.
Q8 T/F Scaling law에서 모델 성능은 모델 크기(N), 데이터셋 크기(D), 컴퓨팅(C) 각각과 멱법칙(power-law) 관계를 보인다.
TRUE — 다른 두 요소가 병목이 아닐 때 각 요소와 Cross-entropy loss 간 power-law 관계 성립.
Q9 T/F GPT(Decoder) 아키텍처는 양방향 셀프 어텐션(Bidirectional self-attention)을 사용한다.
FALSE — GPT(Decoder)는 단방향(Unidirectional) 셀프 어텐션. BERT(Encoder)가 양방향.
Q10 T/F Nucleus sampling(Top-p)은 상위 p 퍼센트 확률 질량을 포함하는 최소 어휘 집합에서 샘플링한다.
TRUE — Top-k의 단점(확률 분포 형태 무시)을 보완. 일반적으로 p=0.9 사용.
Q11 T/F In-context learning은 GPT-2 논문에서 처음 연구된 개념이다.
FALSE — GPT-3 논문에서 처음 연구됨. ICL은 GPT-3의 주요 발견 중 하나.
Q12 T/F BERT는 Masked Language Modeling(MLM)을 사전학습 목표로 사용한다.
TRUE — BERT: MLM(단어 15% 마스킹 후 예측) + NSP(다음 문장 예측) 두 가지 사전학습 목표 사용.
Q13 T/F Greedy decoding은 동일한 입력에 여러 번 실행해도 항상 같은 출력을 보장한다.
TRUE — Greedy decoding의 장점: Deterministic(결정론적). 단점: globally optimal solution 보장 안됨, 다양성 없음.
Q14 T/F Fine-tuning 시 PEFT는 모든 모델 파라미터를 업데이트하는 방식이다.
FALSE — PEFT(Parameter Efficient Fine-tuning)는 소수의 파라미터만 업데이트. Full fine-tuning의 비용 문제 해결.
Q15 T/F The Pile은 800GB 이상의 22개 서브데이터셋으로 구성된 사전학습 코퍼스다.
TRUE — 슬라이드 직접 인용: The Pile: 22 sub-datasets (>800GB). 대형 언어모델 사전학습에 널리 사용.

7강: Retrieval-Augmented Generation (RAG)

Q16 T/F Extractive QA는 주어진 문맥에서 텍스트 span을 그대로 추출하여 답변한다.
TRUE — Extractive QA = Reading Comprehension. BERT 같은 encoder-only 모델로 수행. ↔ Abstractive QA는 재구성.
Q17 T/F Parametric knowledge는 모델 파라미터 외부의 데이터베이스에 저장된 지식이다.
FALSE — Parametric knowledge = 모델 파라미터 내부에 인코딩된 지식. 외부 = non-parametric knowledge.
Q18 T/F TF-IDF는 원시 빈도수(raw count)가 아닌 로그 스케일로 변환한 TF를 사용한다.
TRUE — 100번 등장이 10번보다 10배 중요하지 않음. 로그 스케일로 squash: TF = 1 + log(count) (count>0일 때).
Q19 T/F Bi-encoder는 쿼리와 문서를 함께 처리하여 상호 작용(interaction)을 포착한다.
FALSE — Bi-encoder는 쿼리/문서를 독립적으로 인코딩 → 상호 작용 포착 불가. Cross-encoder가 함께 처리.
Q20 T/F Cross-encoder는 문서 벡터를 미리 계산(precompute)해 둘 수 있어 대규모 검색에 적합하다.
FALSE — 이것은 Bi-encoder의 장점. Cross-encoder는 쿼리-문서 쌍을 매번 처리해야 하므로 대규모 검색에 비적합(scalability 낮음).
Q21 T/F Recall = |R|/|T| (검색된 관련 문서 수 / 전체 검색 결과 수)이다.
FALSE — Precision = |R|/|T|. Recall = |R|/|U| (전체 컬렉션의 관련 문서 수). 공식 혼동 주의!
Q22 T/F RAG-Token 모델은 시퀀스 내 토큰마다 다른 검색 문서를 사용할 수 있다.
TRUE — RAG-Token: 각 생성 토큰에서 주변화(marginalization) 수행 → 토큰마다 다른 문서 사용 가능. ↔ RAG-Sequence: 전체 시퀀스에 동일 문서.
Q23 T/F Dense retrieval은 정확한 단어 일치(exact word overlap)에만 의존한다.
FALSE — 이것은 Sparse retrieval(TF-IDF)의 특성. Dense retrieval은 의미적 유사도(semantic similarity) 기반.
Q24 T/F Hallucination은 LLM이 사실과 다르지만 그럴듯하게 들리는 정보를 생성하는 현상이다.
TRUE — Hallucination 정의: factually incorrect, misleading, or fabricated information that sounds plausible. RAG의 주요 해결 동기.
Q25 T/F 모든 문서에 등장하는 단어(DF=N)의 IDF는 최대값을 가진다.
FALSE — IDF = log(N/DF) = log(N/N) = log(1) = 0. 모든 문서에 등장하는 단어는 변별력 없음 → IDF=0 (최솟값).
Q26 T/F Open-book QA는 외부 지식 소스를 참조하지 않고 답변한다.
FALSE — Open-book QA는 외부 지식 소스 접근 가능. Closed-book QA가 외부 정보 없이 답변.
Q27 T/F FFN(Feedforward Network) 파라미터는 트랜스포머 전체 파라미터의 약 2/3를 차지한다.
TRUE — 슬라이드 직접 인용. FFN(xi) = ReLU(xi·W1)·W2로 2개의 대형 weight matrix 포함.
Q28 T/F Non-parametric knowledge는 모델 재학습 없이 지식 베이스만 업데이트하여 갱신할 수 있다.
TRUE — Non-parametric 지식의 장점: easier updates, 모델 크기 증가 없이 정보 추가 가능, interpretability 향상.
Q29 T/F Average Precision(AP)은 관련 문서가 검색될 때마다의 Precision@k 값들의 평균이다.
TRUE — AP = (1/|R|) × Σ P@k × I(dk is relevant). 관련 문서가 상위에 있을수록 AP 높음.
Q30 T/F REALM은 Encoder 사전학습(BERT 스타일)에 RAG를 통합한 최초의 논문이다.
TRUE — REALM(2020): Retrieval-Augmented Language Model pre-training. MLM loss를 검색된 콘텐츠 조건부로 계산.

8강: LLM Reasoning & Post-training

Q31 T/F Chain-of-thought(CoT) 프롬프팅은 소규모 모델(<7B)에서 가장 효과적이다.
FALSE — CoT는 대형 모델에서 효과적. 소규모 모델에는 오히려 성능이 떨어질 수 있음. 슬라이드: "CoT is especially effective for large models".
Q32 T/F "Let's think step by step"를 답변 앞에 붙이면 Zero-shot CoT를 유발할 수 있다.
TRUE — Zero-shot CoT: few-shot 예제 없이 "Let's think step by step"만으로 단계별 추론 유발 가능.
Q33 T/F Self-consistency CoT는 동일 프롬프트에 여러 번 샘플링 후 다수결 투표로 최종 답을 선택한다.
TRUE — 직관: 여러 다른 추론 경로가 같은 답에 수렴하면 신뢰도 증가. 온도 샘플링으로 다양한 추론 경로 생성.
Q34 T/F RLVR에서 검증 가능한 정답(verifiably correct)이면 이진 보상(binary reward)을 받는다.
TRUE — RLVR: Fine-tune policy model(LLM) using RL. Verifiably correct → reward=1, incorrect → reward=0. OpenAI o1, DeepSeek-R1의 핵심 기법.
Q35 T/F GRPO(Group Relative Policy Optimization)는 PPO와 달리 critic 모델이 필요 없다.
TRUE — GRPO: PPO의 변형으로 critic model 없이, 그룹의 상대적 보상으로 advantage 추정. DeepSeek-R1에서 사용.
Q36 T/F 연역적 추론(Deductive reasoning)은 특정 관찰에서 일반화된 결론을 이끌어낸다.
FALSE — 이것은 귀납적 추론(Inductive). 연역적 추론: 일반 원칙 → 특정 결론. "All humans are mortal + Socrates is human → Socrates is mortal".
Q37 T/F GSM8K는 12.5K의 경쟁 수학 문제로 구성된 벤치마크이다.
FALSE — GSM8K: 8.5K 초등학교 수준 수학 문제. 12.5K 경쟁 수학 문제는 MATH 벤치마크.
Q38 T/F Test-time scaling은 학습 시간(training time) 컴퓨팅을 늘려 성능을 향상시킨다.
FALSE — Test-time scaling은 추론 시(inference time) 컴퓨팅 증가. 방법: self-consistency, long CoT, beam/tree search, iterative refinement.
Q39 T/F Instruction tuning은 자기지도학습(self-supervised learning)의 일종이다.
FALSE — Instruction tuning은 지도학습(supervised learning). 사전학습이 self-supervised. 인간이 작성한 응답(annotation) 사용.
Q40 T/F 소규모 모델(<8B)에 instruction tuning을 적용하면 일반화 성능이 오히려 저하될 수 있다.
TRUE — 슬라이드 직접 인용: "Instruction tuning can hurt small model (<8B) generalization". 대형 모델에는 반대로 크게 향상.
Q41 T/F PPO는 정책 업데이트 안정성을 위해 클립(clipped) 목적함수를 사용한다.
TRUE — PPO: Clipped surrogate objective → 너무 큰 정책 업데이트 방지. GAE(Generalized Advantage Estimation)로 분산 감소.
Q42 T/F LLM Alignment의 HHH 기준은 Helpful, Honest, Harmless이다.
TRUE — Askell et al. 2021의 HHH: Helpful(유용함), Honest(정직함), Harmless(무해함). ChatGPT 정렬의 핵심 기준.
Q43 T/F 사전학습(Pretraining)의 목표는 특정 태스크 지시사항을 잘 따르도록 학습하는 것이다.
FALSE — 이것은 Instruction tuning의 목표. 사전학습 목표: 다음 토큰 예측(language modeling), 광범위한 언어 패턴·지식 학습.
Q44 T/F FLAN은 62개 데이터셋, 12개 태스크 클러스터로 구성된 instruction tuning 데이터셋이다.
TRUE — 슬라이드 직접 인용. 더 많은 클러스터/태스크 사용 → 미등록 클러스터에 대한 일반화 향상.
Q45 T/F RLVR은 지도학습과 달리 모델 자신의 생성 분포에서 학습하여 분포 불일치 문제를 해소한다.
TRUE — RLVR의 장점 중 하나: distribution mismatch 해소. 지도학습은 사람이 만든 데이터 분포와 모델 분포가 다를 수 있음.

9강: LLM Agents

Q46 T/F RLHF에서 인간 평가자는 응답에 1~10의 절대 점수를 직접 부여한다.
FALSE — RLHF는 쌍 비교(pairwise comparison) 방식. 절대 점수는 평가자마다 기준이 달라 일관성 부족. "Humans are better at relative judgments than absolute ones".
Q47 T/F RLHF에서 KL 발산 패널티는 정책 모델이 초기 SFT 모델에서 너무 멀리 벗어나는 것을 방지한다.
TRUE — J(θ) = E[r(y)] - β·KL(π_θ || π_ref). β가 클수록 초기 모델과의 차이를 강하게 억제 → reward hacking 방지.
Q48 T/F Early fusion은 각 모달리티를 별도로 처리한 후 표현을 결합하는 방식이다.
FALSE — 이것은 Late fusion. Early fusion: 처리 전 raw input 데이터를 먼저 결합. Late fusion: 각 모달리티 처리 후 표현 결합.
Q49 T/F LLaVA는 CLIP 비전 인코더와 대형 언어 모델(LLaMA)을 결합한 멀티모달 모델이다.
TRUE — LLaVA: Large Language and Vision Assistant. CLIP(비전) + LLaMA(언어). 프로젝션 행렬 W로 시각 임베딩 → 언어 공간 변환.
Q50 T/F Toolformer는 LLM이 언제, 어떤 도구를 사용할지 자동으로 결정하도록 학습된다.
TRUE — Toolformer: train LMs to use various tools and automatically decide when and how to use which tool. 도구 유형: 계산기, 위키피디아 검색, QA 시스템, 번역기.
Q51 T/F Reward hacking이란 LLM이 실제 원하는 행동 없이 보상 모델의 허점을 이용해 높은 보상을 얻는 것이다.
TRUE — RLHF의 주요 위험 중 하나. Mode collapse(좁은 출력 다양성), 사전학습 지식 손실도 함께 발생 가능.
Q52 T/F Instruction tuning의 단점 중 하나는 Human annotation의 비용이 높다는 것이다.
TRUE — RLHF가 instruction tuning보다 annotation 효율적인 이유: RLHF는 "어떤 게 더 나은가"만 판단하면 됨(쌍 비교). Instruction tuning은 전체 응답 작성 필요.
Q53 T/F InCoder는 코드 삽입(infilling)을 위해 Causal Masking을 사용하여 학습된다.
TRUE — InCoder: 코드 span을 샘플링하여 문서 끝으로 이동 → 양방향 맥락 조건부로 마스크된 내용 생성 학습. 코드는 좌→우 단방향 작성이 아님.
Q54 T/F SWE-Bench는 실제 Python 저장소의 GitHub 이슈를 해결하는 패치 생성 능력을 평가한다.
TRUE — SWE-Bench: 실제 GitHub 이슈 + merged PR 솔루션 쌍. LLM이 생성한 패치를 실제 테스트로 평가.
Q55 T/F Mode collapse는 RLHF에서 LLM이 다양성 없이 좁은 범위의 출력만 생성하는 문제다.
TRUE — Naïve reward 최대화의 문제: reward model 허점 이용 + mode collapse + 사전학습 지식 손실. KL 패널티로 완화.
Q56 T/F Language agent의 기반은 LLM이며, 자연어 이해·생성·추론 능력을 활용한다.
TRUE — Language agents: LLM이 기반. NLU(user input 이해) + NLG(응답/행동 생성) + Reasoning(다단계 문제 해결) 모두 활용.
Q57 T/F 멀티모달 LLM의 학습 데이터는 단일 모달리티 쌍으로 구성되어야 한다.
FALSE — 멀티모달 데이터셋은 다양한 모달리티의 paired examples(예: 이미지-텍스트 쌍) 필요. "teach the model the relationships between different types of data".
Q58 T/F 도구 사용 능력(Tool Usage Ability)은 모델 규모와 무관하다.
FALSE — 슬라이드: "Larger models more effectively learn how to appropriately use tools". 소규모 모델은 도구 사용 능력이 낮음.
Q59 T/F RLHF에서 보상 모델은 LLM 생성 응답에 스칼라(scalar) 점수를 출력한다.
TRUE — Reward model: 마지막 토큰 표현에 linear layer 적용 → scalar score 출력. Higher reward = more preferred.
Q60 T/F Open-ended 창의적 생성 태스크에서 instruction tuning이 RLHF보다 정답을 판단하기 쉽다.
FALSE — Open-ended 창의적 생성은 단일 정답 없음 → instruction tuning의 한계. RLHF는 "어떤 것이 더 창의적/매력적인가"로 선호 판단 가능.

PART 3: 단답형 문제

6강: LLMs & In-context Learning

SA-1 단답 LoRA에서 ΔW를 BA로 근사할 때, r은 d보다 훨씬 작아야 한다. 이 조건(r ≪ d)이 필요한 이유를 설명하라.
저랭크 근사(low-rank approximation)를 통해 파라미터 수를 극적으로 줄이기 위해. d×d → d×r + r×d = 2dr (r≪d이면 2dr≪d²). 대형 언어모델은 과잉 파라미터화(overparameterization)되어 있어 실제 업데이트가 저랭크 구조를 가진다는 경험적 관찰에 근거.
SA-2 단답 Scaling law에서 LLM 성능을 결정하는 3가지 주요 요소를 나열하라.
① 모델 크기(N: number of parameters) ② 데이터셋 크기(D: amount of training data/tokens) ③ 컴퓨팅(C: FLOPs, floating point operations). 세 요소 각각과 Cross-entropy loss의 관계가 power-law를 따름.
SA-3 단답 In-context learning이 few-shot learning의 일종인 이유를 설명하고, 파라미터 업데이트 여부를 밝혀라.
프롬프트에 포함된 소수의 입출력 예제(few-shot examples)를 보고 새로운 입력의 출력을 예측하므로 few-shot learning의 일종. 모델 파라미터 업데이트 없음(No parameter updates). GPT-3 논문에서 최초 연구.
SA-4 단답 Greedy decoding의 장점 2가지와 단점 2가지를 나열하라.
장점: ① 구현 간단(Simplicity) ② 결정론적(Deterministic) — 동일 입력에 항상 동일 출력
단점: ① 전역 최적해 보장 불가(Suboptimal solutions) ② 다양성 없음(Lack of diversity) — 같은 입력에 다른 출력 생성 불가
SA-5 단답 Emergent ability란 무엇이며, 왜 소규모 모델 성능으로 예측할 수 없는가?
Emergent ability: 명시적으로 학습하지 않았지만 모델 규모가 특정 임계값(threshold)을 초과하면 갑자기 나타나는 능력. 소규모 모델에서는 random 수준 성능을 보이다 임계 규모 이후 급격히 향상되기 때문에, 소규모 모델 성능 추외(extrapolation)로는 예측 불가.

7강: Retrieval-Augmented Generation (RAG)

SA-6 단답 Closed-domain QA와 Open-domain QA의 차이를 설명하라.
Closed-domain QA: 특정 도메인(의료, 법률 등) 내의 질문에만 답변. 해당 도메인 지식으로 학습된 전문 모델.
Open-domain QA: 어떤 도메인의 질문에도 답변. 웹/대규모 코퍼스 등 광범위한 외부 지식 소스 활용. 대부분의 LLM 응용이 Open-domain QA 설정.
SA-7 단답 Bi-encoder와 Cross-encoder의 장단점을 각각 설명하고, 어떤 상황에 적합한지 서술하라.
Bi-encoder: 장점 - 문서 벡터 사전 계산 가능, 대규모 검색에 적합. 단점 - 쿼리-문서 상호작용 포착 불가.
Cross-encoder: 장점 - 쿼리-문서 간 섬세한 상호작용 포착. 단점 - 대규모 코퍼스에 비적합(scalability ↓).
실무: 1단계 대규모 검색(Bi-encoder) → 2단계 재순위(Cross-encoder) 방식으로 결합 사용.
SA-8 단답 Hallucination이 발생하는 주요 원인 3가지를 서술하라.
① Limited knowledge: 학습 데이터 범위 밖의 정보에 대해 그럴듯한 오답 생성
② Overgeneralization: 한 맥락에서 학습한 패턴을 적용 불가한 다른 맥락에 적용
③ Lack of common sense: 상식적 추론 능력 부족으로 비현실적 답변 생성
SA-9 단답 RAG-Sequence와 RAG-Token의 차이를 설명하라.
RAG-Sequence: 동일한 검색 문서를 전체 시퀀스 생성에 사용. 검색 문서를 단일 잠재 변수(latent variable)로 처리. 시퀀스 레벨에서 주변화(marginalization).
RAG-Token: 각 토큰 생성마다 다른 검색 문서 사용 가능. 토큰 레벨에서 주변화. 더 유연하지만 계산 비용 높음.
SA-10 단답 Non-parametric knowledge가 parametric knowledge 대비 갖는 이점 3가지를 서술하라.
① 모델 크기 증가 없이 더 많은 정보 활용 가능
② 지식 업데이트/수정이 쉬움 (모델 재학습 불필요)
③ 모델 해석 가능성(interpretability) 향상 — 어떤 문서에서 답변이 생성됐는지 추적 가능

8강: LLM Reasoning & Post-training

SA-11 단답 Chain-of-thought(CoT) 프롬프팅의 핵심 아이디어를 설명하고, Self-consistency CoT와의 차이를 서술하라.
CoT: 모델이 복잡한 문제를 단계별 추론 과정으로 분해하여 답변. 즉각적 답변 대신 논리적 사고 흐름을 순차적으로 설명하도록 유도.
Self-consistency CoT: 동일 프롬프트에 온도 샘플링으로 여러 번 CoT 실행 → 다양한 추론 경로 생성 → majority voting으로 최종 답 선택. 신뢰도 향상.
SA-12 단답 RLVR이 지도학습(Supervised Learning) 대비 갖는 장점 3가지를 설명하라.
① Data scalability: 인간이 전체 정답 작성 불필요. 자동 검증기(verifier)로 이진 보상 부여 → 데이터 확장성 우수
② Imitation vs. Optimization: SL은 사람 추론 모방(suboptimal 가능). RLVR은 최종 정답 최적화 → 모델이 자체 효율적 추론 경로 발견
③ Distribution match: 모델 자신의 생성 분포에서 학습 → 학습-추론 분포 불일치 해소
SA-13 단답 Instruction tuning과 사전학습(Pretraining)의 차이를 감독 방식, 태스크 형식, 목표 측면에서 비교하라.

SA-14 단답 LLM Alignment가 필요한 이유(pretrained LLM의 문제점) 3가지를 설명하라.
① Objective mismatch: 사전학습 목표(다음 토큰 예측)는 인간 의도/가치 이해를 포함하지 않음
② Training data bias: 인터넷 텍스트는 편향, 유해, 오해의 소지 있는 내용 포함. 모델이 좋고 나쁜 행동을 구분 못함
③ Over-generalization: 특정 맥락에서 부적절한 출력 가능. 의도한 윤리/정직 기준과 불일치 가능
SA-15 단답 Test-time scaling이란 무엇이며, 그 방법 3가지를 제시하라.
Test-time scaling: 추론 시(inference time) 더 많은 컴퓨팅을 사용하여 고품질 답변 생성.
방법:
① Self-consistency(majority voting): 여러 번 샘플링 후 다수결
② Long CoT: 더 긴 추론 체인(DeepSeek-R1, o1)
③ Beam/Tree Search: 여러 추론 경로 동시 탐색, 막힌 경우 백트래킹
(+ Iterative Refinement: 초기 응답 반복 개선)

9강: LLM Agents

SA-16 단답 RLHF에서 보상 모델 학습에 쌍 비교(pairwise comparison)를 사용하는 이유를 설명하라.
인간 평가자는 절대 점수(예: 1~10)보다 상대적 판단(어느 것이 더 나은가)을 일관되게 수행하는 능력이 뛰어남. 절대 점수는 평가자마다 기준이 달라 inconsistency 발생. 쌍 비교는 preference data로 Bradley-Terry 목적함수로 reward model 학습.
SA-17 단답 LLaVA의 아키텍처에서 프로젝션 행렬 W의 역할을 설명하라.
비전 인코더(CLIP)의 출력 임베딩 Z_v를 LLM이 처리할 수 있는 텍스트 임베딩 공간으로 변환: H_v = W × Z_v. 이후 H_v(시각 토큰)와 H_q(텍스트 토큰)를 concatenate하여 LLM에 입력. 초기 학습 단계에서 비전 인코더와 LLM은 frozen, W만 학습.
SA-18 단답 Naïve한 RLHF 보상 최대화(KL 패널티 없이)의 문제점 3가지를 설명하라.
① Reward hacking: 보상 모델 허점 이용 → 실제 바람직한 행동 없이 높은 보상 달성
② Mode collapse: 좁은 출력 분포에 수렴 → 다양성 부족, 다양한 상황에 일반화 실패
③ Loss of pretrained knowledge: 보상 모델 과최적화로 초기 사전학습 지식(문법, 사실성 등) 손실
SA-19 단답 Instruction tuning의 한계 4가지를 설명하고, RLHF가 각 한계를 어떻게 해결하는지 서술하라.
① Costly annotation: 전체 응답 작성 필요 → RLHF: 선호 레이블(어느 게 더 나은가)만 수집
② Open-ended generation: 단일 정답 없는 창의적 태스크에 취약 → RLHF: 인간 선호로 창의성 평가 가능
③ Token-level learning: 모든 토큰 오류를 동등하게 패널티 → RLHF: 오류 중요도를 인간 피드백으로 우선순위화
④ Suboptimal human answers: 사람이 최적이 아닌 응답 작성 가능 → RLHF: 여러 선택지 중 더 나은 것 고르기가 처음부터 쓰기보다 쉬움
SA-20 단답 Toolformer에서 API 호출이 실제로 유용한지 필터링하는 기준을 설명하라.
API 호출이 미래 토큰 생성의 loss를 감소시키는지 여부로 필터링. 도움이 되는 API 호출 = 해당 API 결과를 보고 다음 토큰을 더 잘 예측하는 경우(loss ↓). 도움이 되지 않는 API 호출은 필터링하여 학습 데이터에서 제외. In-context learning 방식으로 새 데이터에 대한 API call 생성.

PART 4: 자주 질문한 개념 연결 문제

SA-21 단답 RLHF/RLVR 관점에서 state, policy, action, reward를 LLM에 매핑하고, state가 사전학습 지식인지 설명하라.
State: 사용자 프롬프트, 대화 기록, 지금까지 생성한 토큰. Policy: LLM 자체 πθ. Action: 다음 토큰 또는 전체 응답 생성. Reward: 응답 품질 점수. State는 사전학습 지식이 아니며, 사전학습 지식은 policy model의 파라미터 θ 안에 저장된 parametric knowledge이다.
SA-22 단답 RLHF와 RLVR의 reward 출처 차이를 설명하라.
RLHF: 인간 pairwise preference로 reward model을 학습하고, 그 reward model이 응답에 scalar 점수를 준다. RLVR: 정답 비교기, unit test, 규칙 기반 checker 같은 verifier가 자동으로 보상을 준다. RLHF는 인간 선호 정렬에 강하고, RLVR은 수학·코드처럼 검증 가능한 추론 태스크에 강하다.
SA-23 단답 Bradley-Terry 방식이 pairwise preference 모델링인 이유를 sigmoid와 연결해 설명하라.
Pairwise preference는 같은 prompt의 두 응답 y_w, y_l 중 사람이 더 선호한 응답을 고르는 데이터이다. Bradley-Terry는 두 응답의 reward 차이를 이용해 P(y_w > y_l)=σ(r_w-r_l)로 선호 확률을 모델링한다. reward 차이가 클수록 sigmoid 출력이 1에 가까워져 y_w가 더 선호될 확률이 커진다.
SA-24 단답 Sigmoid와 Softmax의 차이를 LLM 예시와 함께 설명하라.
Sigmoid: 하나의 점수 또는 독립 점수를 0~1로 바꾼다. RLHF의 Bradley-Terry에서 reward 차이 r_w-r_l을 선호 확률로 바꿀 때 쓴다. Softmax: 여러 후보 점수를 합이 1인 확률분포로 바꾼다. LLM 다음 토큰 예측에서 vocabulary 전체 logits를 확률분포로 만들 때 쓴다.
SA-25 단답 RAG-Sequence와 RAG-Token의 차이, 그리고 현대 RAG에서 흔히 쓰이는 방식의 차이를 설명하라.
RAG-Sequence: 전체 출력 시퀀스가 같은 문서 또는 문서 집합에 조건화된다. RAG-Token: 각 생성 토큰마다 문서에 대해 marginalization하여 토큰별로 다른 문서를 활용할 수 있다. 다만 현대 실무 RAG는 RAG-Token 수식을 직접 쓰기보다 top-k 문서를 context에 넣고 LLM attention이 필요한 부분을 참고하게 하는 경우가 많다.
SA-26 단답 CoT, Zero-shot CoT, Few-shot CoT, Self-consistency CoT의 관계를 설명하라.
CoT는 모델이 중간 추론 단계를 생성하도록 유도하는 방식이다. Zero-shot CoT는 예시 없이 "Let's think step by step" 같은 지시만 붙이는 방식이고, Few-shot CoT는 풀이 과정이 포함된 예시를 prompt에 넣는 방식이다. Self-consistency CoT는 여러 CoT reasoning path를 temperature sampling으로 생성한 뒤 최종 답을 다수결로 고른다.
SA-27 단답 Emergent ability와 Aha moment의 차이를 설명하라.
Emergent ability: 모델 크기, 데이터, compute가 일정 규모를 넘을 때 특정 능력이 갑자기 나타나는 스케일링 관점의 현상이다. Aha moment: RL post-training 중 모델이 자기검토, 긴 사고 과정 같은 추론 전략을 발견한 것처럼 보이는 학습 과정 관점의 현상이다. 둘 다 갑작스러워 보이지만 발생 맥락이 다르다.
SA-28 단답 LoRA와 LLaVA가 같은 low-rank 철학인지 구분하라.
LoRA는 ΔW≈BA로 기존 가중치 업데이트를 저랭크 행렬로 근사하는 PEFT 방법이므로 low-rank가 핵심이다. LLaVA는 CLIP vision encoder의 시각 feature를 LLM embedding 공간으로 projection하여 이미지+텍스트를 처리하는 멀티모달 아키텍처이다. 둘 다 pretrained model을 효율적으로 재사용한다는 철학은 공유하지만, LLaVA의 projection이 곧 LoRA식 low-rank update를 뜻하지는 않는다.
SA-29 단답 Prompt engineering, ICL, soft prompt tuning을 파라미터 업데이트 여부로 구분하라.
Prompt engineering: 사람이 자연어 프롬프트를 수정하며 학습 없음. ICL: 프롬프트 안 예시로 추론 시점에 패턴을 따르며 파라미터 업데이트 없음. Soft prompt tuning: 자연어가 아닌 학습 가능한 soft prompt embedding 벡터를 gradient로 업데이트하는 PEFT 방식이다.
SA-30 단답 Alignment가 "인간과 모델의 생각을 같게 만드는 것"이 아닌 이유를 설명하라.
Alignment는 모델의 내부 생각을 인간과 동일하게 만드는 것이 아니라, 모델의 출력과 행동을 인간의 의도·선호·안전 기준에 맞추는 것이다. 대표 기준은 Helpful, Honest, Harmless이며, instruction tuning, RLHF, RLVR, KL penalty 같은 post-training 방법으로 사전학습 목표와 인간 선호 사이의 불일치를 줄인다.
